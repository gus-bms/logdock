# LogDock · 로그독

여러 서비스의 로그가 모이는 곳.

LogDock은 여러 서비스와 서버의 로그를 한곳에서 수집·검색하기 위한 self-hosted 로그 관리 도구입니다. 서비스의 언어와 실행 방식에 맞춰 수집기를 연결하고, 공통 필드로 로그가 발생한 서비스와 서버를 찾는 것을 목표로 합니다.

**현재는 기능 명세·설계 검토 단계입니다.** 기존 NestJS 상태 확인 API와 React의 API 연결 상태 화면만 구현되어 있습니다. 로그 수집·저장·검색, 서비스 등록과 운영 인증은 아직 구현하지 않았습니다. 기존 scaffold는 최종 아키텍처 승인을 뜻하지 않습니다.

## 설계 방향

- 서비스명, 서버 목록과 로그 경로는 각 배포 환경에서 설정합니다.
- 파일 로그, 프로세스 관리자와 컨테이너 로그는 소스별 수집 설정으로 다룹니다.
- 수집기·저장/검색 엔진·백엔드 최종 선택은 기능·품질 요구를 검토한 뒤 정합니다. Loki 등 초기 제안은 아직 확정하지 않았습니다.
- 기존 서비스 보호와 agent 자원 최소화·제한을 최우선으로 검토합니다.
- 클라우드 사업자, 서버 수와 보관 기간을 애플리케이션에 고정하지 않습니다.
- 공개 예시는 합성 데이터를 사용하고, 실제 운영 설정과 자격 증명은 저장소 밖에서 주입합니다.

현재 구현과 설계 검토의 경계는 [아키텍처 문서](docs/architecture.md)에 정리되어 있습니다.

## 문서와 세션 이어가기

다른 환경에서 이어갈 때는 [handoff](docs/HANDOFF.md)와 [결정 기록](docs/decisions.md)을 먼저 읽으세요. 기능 후보·수집 명세·상용 서비스 조사·검토용 PDF는 [문서 안내](docs/README.md)에 모았습니다. 문서의 추천안과 검증 시나리오는 구현 승인이나 시험 완료를 뜻하지 않습니다.

## 시작하기

- Node.js 24.22.2 LTS (`.node-version` 기준, 지원 범위 `>=24.22.2 <25`)
- npm 11.x

fnm을 사용한다면 저장소 루트에서 프로젝트 버전을 선택할 수 있습니다.

```sh
fnm install
fnm use
```

디렉터리 이동 시 자동 전환 여부는 각 사용자의 fnm 셸 설정에 따릅니다.

의존성을 설치합니다.

```sh
npm ci
```

두 터미널에서 API와 웹을 각각 실행합니다.

```sh
npm run dev:api
```

```sh
npm run dev:web
```

- 웹: <http://127.0.0.1:5173>
- API 상태: <http://127.0.0.1:3001/api/health>
- 웹의 `/api` 요청은 Vite 개발 프록시를 통해 로컬 API로 전달됩니다.

상태 확인 API는 다음과 같이 응답합니다.

```json
{
  "status": "ok",
  "service": "logdock-api"
}
```

웹 화면은 API 응답의 정상·실패 상태와 재시도 기능을 제공합니다. 이 연결 상태는 로그 수집기나 저장소의 동작 상태를 의미하지 않습니다.

## 개발 명령

| 명령 | 용도 |
| --- | --- |
| `npm run dev:api` | NestJS API 개발 서버 |
| `npm run dev:web` | React·Vite 개발 서버 |
| `npm run build` | API·웹 빌드 |
| `npm run typecheck` | TypeScript 검사 |

빌드·타입 검사 후 상태 확인 API의 HTTP 응답과 웹의 연결 상태를 확인할 수 있습니다.

## 배포 설정과 로그 데이터

현재 개발 서버는 로컬 주소에 바인딩되며 외부 로그 저장소에 연결하지 않습니다. 운영 배포 구성은 아직 제공하지 않습니다.

향후 저장소 연결 정보와 인증 값은 서버 측 런타임 설정으로 주입합니다. 실제 서버 주소, 조직별 로그 경로, 운영 로그와 자격 증명은 공개 저장소에 커밋하지 않습니다. 브라우저에 전달되는 설정에는 서버 측 비밀 값을 포함하지 않습니다.

로그를 공유하거나 예시로 추가할 때는 합성 데이터를 사용합니다. 실제 로그를 진단 자료로 다룰 때는 인증 정보와 개인 식별 정보를 먼저 제거합니다.
