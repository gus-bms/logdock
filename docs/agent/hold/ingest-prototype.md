# 수신 서버 시제품

- 담당: 없음
- 우선순위: 2
- 선행: 없음
- 다음 할 일: 시작 요청을 받으면 api-contract-draft의 전송 규약 초안에 맞춰 최소 수신 경로부터 만든다
- 막힌 이유: 사용자가 구현 시작을 요청하지 않았다(Go 1.27은 2026-11-05 설치). ClickHouse 연동 시험에는 중앙 서버가 필요하다
- 풀리는 조건: 사용자가 수신 서버 구현 시작을 요청한다
- 마지막 갱신: 2026-11-05

## 목표와 완료 조건

측정 M3·M4·M6(묶음 저장 지연, 동시 검색 때 수신 지연, 강제 종료 때 유실·중복)에 쓸 Go 수신 서버 시제품을 만든다. 제품 구현이 아니라 측정용이며, 범위는 시작할 때 사용자와 정한다.

## 진행 기록

- 2026-11-04 작업 파일을 만들었다.
- 2026-11-05 version-pinning에서 Go를 1.27 계열, ClickHouse를 26.8 LTS로 고정했고(D17 공식 자료 조사 8절) 같은 날 사용자 요청으로 이 PC에 Go 1.27.3을 설치했다. 남은 조건은 구현 시작 요청이다.
- 2026-11-05 시험이 스스로 띄우고 지우는 임시 PostgreSQL에서는 에이전트가 쓰기·DDL을 실행해도 된다는 예외가 생겼다([결정 기록](../../decisions.md)). 수신 서버의 PostgreSQL 쪽 시험(순번·키·세대 번호)은 이 PC에서 돌릴 수 있고, ClickHouse 연동 시험은 여전히 중앙 서버가 필요하다.
