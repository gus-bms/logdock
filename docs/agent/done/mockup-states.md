## 진행 기록

- 2026-11-06 작업 시작. 와이어프레임 상태 목록을 시안과 대조해 빠진 상태를 세 묶음으로 나눴다.
- 2026-11-06 묶음 5 완료. 로그 탐색 시안에 화면 아래 시안 조작 띠와 상태 21개(실행 전, 조회 중, 완료 0건과 수집 문제 요약, 범위 일부 만료, 부분·한도, 시간 초과·오류, 취소 두 가지, 더 보기 위치 만료, 세션 만료, 조건 오류와 이전 결과, 고친 조건 미검색, 조건 저장·이름 겹침·개수 상한, 값 목록, 필드 이름 후보와 연산, 조건 수 상한, 판정 불가만 보기, 알림 규칙 상한)를 더했다. 1차 리뷰에서 숨김 속성이 부품의 `display`에 덮여 안내·더 보기·그래프 덮개가 남는 문제, 끝나지 않은 결과의 범례·항목 건수, 부분 결과의 미완료 구간 막대와 건수를 찾아 고쳤고, 2차 리뷰에서 그래프 덮개가 늘 그래프를 가리던 원인을 찾아 고쳤다. 3차 확인에서 22개 상태 모두 의도대로 그려지고 콘솔 오류가 없었다. 남긴 것: 기본 장면은 필드 조건이 없는데 `판정 불가 37건 제외`를 보인다(승인된 기본 장면이라 그대로 두고 기록만 함).
- 2026-11-06 묶음 6 완료. 로그 탐색 시안의 `상세 UI-03`에 상태 17개(본문 접음·줄바꿈 끔·JSON 펼침·ANSI, 시각 정상·대체·의심·시간대 추정, 해석 실패, 필드 일부 생략, 필드로 조건 추가, 복사, 닫고 돌아감, 가져올 수 없음 두 가지, 세션 만료)를 더했다. 디자인 시스템 11절 WQ-21에 맞춰 패널의 복사 아이콘 하나를 `본문 복사`·`필드 복사` 두 버튼으로 바꿨다(기본 장면도 바뀜). 1차 리뷰에서 본문 머리 버튼 벌어짐, 시각 대체 행을 열었는데 첫 행 내용이 남던 문제, 버튼 글자가 길어 머리 줄이 꺾이던 문제, 가져올 수 없음의 버튼 폭과 행·머리 불일치를 고쳤다. 2차 확인에서 17개 상태 모두 머리 한 줄, 고른 행과 패널 내용 일치, 콘솔 오류 없음.
- 2026-11-06 묶음 7 완료. 수집 연결 상세 시안의 시안 조작을 화면 아래 띠와 고르기 목록으로 바꾸고 상태를 더했다: 보관된 연결(재활성, WQ-56·67·68), 재활성 직후, 보고를 받은 적 없음(대기량 미확인), 설정 수정 폼과 확정 뒤, 보관 뒤 진행 단계, CM-07 재인증 유효·비밀번호 오류·감사 장애 보류·긴급 키 폐기, CM-01 배너 여러 개·조치 필요 미확인, CM-08 토스트 여러 개. 원래 설정 수정은 늘 보류 토스트만 띄웠는데 폼 → 확인 창 → 새 설정 버전으로 바꾸고, 보류는 감사 장애 상태에서만 나게 했다. 1차 리뷰에서 폼 제목이 상단 메뉴에 가려지는 문제, 배너 링크 줄바꿈, 상태마다 어긋나던 설정 버전(원래 있던 수집 문제·미관측·복구 보류 포함)을 고쳤고, 2차 확인에서 버전 일치·확인 창 두 가지·감사 장애 보류를 확인하고 보류 토스트의 조사를 고쳤다. 어두운 화면에서 배너 `확인` 단추가 보이지 않아 공통 부품을 고쳤다. 콘솔 오류 없음, 대비 60쌍 통과.
- 2026-11-06 세 묶음을 마치고 디자인 시스템 문서 13·14절과 파일 표, `docs/README.md`, `docs/agent/README.md`를 고쳐 작업을 끝냈다. 커밋은 하지 않았다.
