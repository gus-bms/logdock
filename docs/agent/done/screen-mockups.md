## 목표와 완료 조건

디자인 시스템 초안(design-system)에서 대표 시안 2개(UI-02, UI-12)만 만들었다. 와이어프레임에 있는 나머지 첫 출시 화면을 같은 기준값·부품으로 정적 HTML 시안으로 만든다. 화면 구현(React)이 아니며 확정 배치도 아니다.

- 묶음 순서(2026-11-06 사용자 A안):
  1. 수집 연결: UI-10 목록, UI-11 등록
  2. 알림: UI-06 규칙 목록, UI-07 규칙 편집, UI-08 규칙 상세, UI-09 사건 상세
  3. 시스템: UI-13 저장 공간, UI-14 메일 상태, UI-15 감사 이력, UI-16 계정
  4. 검색 보조: UI-01 로그인, UI-04 주변 로그, UI-05 저장 검색. 함께 로그 탐색 시안(UI-02)에 알림 조사 모드와 `현재 조건으로 알림 규칙 만들기` 버튼의 편집 연결·상한 상태(WQ-34)를 더한다(2026-11-06 묶음 2 다시 점검에서 넘김)
- 묶음마다 시안 파일 하나(`docs/design/sample-*.html`)를 만들어 Orca 탭에서 띄우고, 사용자 확인을 받은 뒤 다음 묶음으로 간다.
- 와이어프레임 정리표의 기본안과 API 계약 초안(상태 전이, 사유 코드)을 따른다. 그림과 다른 기본안(정리표 4절)은 시안에서 기본안대로 그린다.
- 시안에 필요한 부품은 `components.css`에 더하고 디자인 시스템 문서 10절에 적는다. 대비 검사(`check-contrast.mjs`)를 다시 돌린다.
- 완료: 네 묶음 시안이 있고 디자인 시스템 문서 13·14절과 `docs/README.md`가 갱신됨.
