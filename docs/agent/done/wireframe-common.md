## 진행 기록

- 2026-11-04 작업 파일을 만들었다.
- 2026-11-05 공통 요소 CM-01~CM-07, 공통 스타일 `wireframe.css`, 파일 목록 `index.html`을 `docs/wireframes/`에 만들었다. 다른 묶음이 서로 링크할 수 있게 화면 파일 이름을 목록에 고정했다. 확인한 것은 정적 점검(외부 자원 없음, HTML 구조)과 로컬 Chrome 렌더링이고, 실제 화면 구현이나 사용자 검토는 아니다.
- 2026-11-05 문서에 없어 검토 단계로 넘길 점 5건을 각 파일 주석에 `검토 항목`으로 남겼다. 수집 연결의 `조치 필요` 기준, 메일 최종 실패 배너의 이동 화면, 지나간 일을 알리는 배너를 내리는 시점, 관측 상태가 동시에 둘 이상일 때의 표시, 감사 장애로 보류한 작업의 복구 뒤 처리다. 문서에 없는 작은 배치 선택은 주석에 `와이어프레임 표기`로 구분했다.
- 2026-11-05 사용자가 공통 요소의 회색조 모양을 그대로 쓰기로 했다. UI-01 로그인과 UI-16 계정과 세션을 그려 묶음 1을 마쳤다. 로그인 전 화면에 감사 기록 장애를 알리지 않는 것, 비밀번호 변경 확인 창에서 현재 비밀번호 칸이 재확인을 겸하는 것, 전체 세션 종료는 재인증 없이 확인만 받는 것은 `와이어프레임 표기`로 남겼다.
