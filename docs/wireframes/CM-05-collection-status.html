CM-05 수집 상태 표시

수집 연결 목록(UI-10)과 상세(UI-12) 등에서 쓰는 상태 표시다. 관리 상태와 관측 상태를 따로 보여 주고 마지막 보고 시각을 함께 쓴다. 여러 단계를 하나의 정상 표시로 합치지 않는다.

근거: 운영 명세 4절 Q05·Q07·Q10 기획안 3절 · 기준: 화면 흐름 명세 1·4절

상태 2. 관리 상태

운영자가 정한 연결의 수명 단계다.

관리 상태뜻함께 보여 줄 사실
등록·연결 대기등록을 확정하고 키와 설정을 줬다. 실제 읽기는 서버에 설정을 적용한 뒤 시작한다.설정을 준 것과 실제 적용·수신 확인을 나눠 보여 준다.
사용등록한 범위에서 수집한다.원래 출처, 설정 버전, 읽기·전송과 최신성.
종료 진행정상 중지 요청으로 읽기·전송·재시도를 멈추는 중이다.중지 완료와 남은 전송 완료를 나눠 보여 준다. 관측 근거 없이 서버의 중지 완료를 단정하지 않는다.
전송 차단키나 등록을 막아 중앙이 새 전송을 받지 않는다. 대기 로그는 보존하고 서버의 읽기 중지는 따로 한다.중앙 차단 결과와 서버의 마지막 보고·미관측. 전송 차단과 읽기 중단을 구분한다.
보관운영자가 명시적으로 고른 상태다. 중앙 새 수신을 막고 과거 로그는 보관 기간까지 검색한다.남은 대기와 미관측을 그대로 보여 준다. 대기 0, 삭제 완료, 서버 중지 완료를 짐작해 쓰지 않는다.
  • 로그가 없거나 오래 조용하다는 이유만으로 보관으로 바꾸지 않는다(Q07-07, Q05·Q07·Q10 기획안 3절).

상태 3. 관측 상태

에이전트 보고와 중앙 관측으로 본 지금의 수집 상태다.

관측 상태뜻표시 예
연결 대기등록했지만 에이전트 보고나 수신 증거가 없다.등록 2026-11-05 09:40:00 · 마지막 보고 없음
관측됨·무로그상태 보고는 있지만 이벤트가 없다. 읽기와 중앙 수신 성공을 단정하지 않는다.마지막 보고 10:14:52 · 받은 이벤트 없음
수집/전송 진행읽고 보내고 있다.마지막 읽기 10:14:50 · 마지막 전송 확인 10:14:51
읽기 일시정지대기 공간이 차거나 자원을 보호하려고 새 읽기를 멈췄다.사유 대기 공간 포화 · 시작 10:02:11 · 대기 512MB · 원본이 회전·삭제되면 유실될 수 있음
설정/복구 확인 필요파일 경계를 판별할 수 없거나 이어 읽을 근거가 없다.복구 근거 없음 · 누락 영향과 서버에서 적용할 방법 보기
디스크 사용 불가에이전트가 대기를 디스크에 쓰지 못한다.쓰기 실패 · 읽기·전송 중단 · 기존 대기는 보존
이벤트 거부 관측크기 상한을 넘은 이벤트를 거부했다. 본문은 남기지 않는다.크기 초과 2건 · 관측 10:05:31 · 적용 상한 N · 이후 수집 계속
전송 오류/보류중앙으로 보내지 못하고 있다.인증 오류 · 재시도 가능한 오류 · 현재 정책 재검사 중 하나로 구분
복구 중밀린 대기를 제한된 속도로 보내고 있다.남은 대기 1.8GB · 새 로그보다 오래된 로그가 먼저 보일 수 있음
관측 오래됨/미확인마지막 보고 뒤로 지금 상태를 관측하지 못한다.마지막 보고 09:31:07 이후 보고 없음(판정 기준 N) · 아래 값은 마지막 보고 기준
시각 확인 필요에이전트 보고 시각과 중앙 시각이 크게 다르거나, 로그 시각이 관측 시각과 일정하게 어긋난다. 수집은 멈추지 않는다.서버 시계 또는 로그 시간대 설정 확인
중단/보관관리 상태(종료 진행·보관)에 따라 수집을 멈췄다.남은 대기 처리 표시
  • 관측 상태 12개와 뜻은 운영 명세 4절을 따른다. 읽기 일시정지는 D01, 설정/복구 확인 필요는 D02·Q06, 디스크 사용 불가는 D05, 이벤트 거부 관측은 D03, 시각 확인 필요는 SD-05다.
  • 표시 예의 용량과 건수는 합성 표시 값이다. 이벤트 크기 상한과 관측 오래됨 판정 기준은 정하지 않았다(7절).
  • WQ-04 설계로 넘김: 관측 상태가 동시에 둘 이상일 때(예: 수집/전송 진행 중 시각 확인 필요) 어떻게 보일지 문서에 없다. 기본안: 해당하는 상태를 모두 배지로 보이고 조치가 필요한 상태를 앞에 둔다.
