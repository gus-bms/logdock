CM-02 시간 범위 선택

로그 탐색(UI-02)과 저장 검색(UI-05)에서 쓰는 시간 범위 선택이다. 시간 기준(발생 시각·수신 시각)과 범위(상대·고정)를 고르고, 실행할 때 절대 범위로 바꿔 적용 범위와 시간대를 표시한다.

근거: Q08-04 SD-06 SD-07 SD-08 Q11 · 기준: 화면 흐름 명세 4절, 조사 명세 3절

  1. 닫힌 상태
  2. 펼침: 상대 범위
  3. 펼침: 고정 범위
  4. 실행 뒤 적용 범위 표시
  5. 수신 시각 기준
  6. 알림 조사 모드로 열림
  7. 입력 오류

상태 1. 닫힌 상태

검색 조건 줄 왼쪽
발생 시각 · 최근 N UTC+09:00
  • 시간 기준의 기본은 발생 시각이다(Q08-04).
  • 검색 화면을 열 때의 기본 범위는 최근 N이며 화면 설계에서 정한다(7절).
  • 표시 시간대는 배포 설정 하나이고 항상 함께 보인다. 사람마다 다르게 고르지 않는다(SD-07).

상태 2. 펼침: 상대 범위

발생 시각 · 최근 NUTC+09:00
시간 기준
발생 시각(기본)수신 시각
발생 시각은 로그에 찍힌 시각입니다. 수신 시각은 중앙이 처음 유효하게 받은 시각으로, 늦게 도착한 로그를 찾을 때 씁니다.
상대 범위고정 범위
최근 N 분 단위: 분 · 시간 · 일
실행할 때 서버 시각으로 절대 범위를 정합니다. 그 뒤에는 범위가 움직이지 않습니다.
취소적용
  • 상대 범위는 실행할 때 서버 시각으로 절대 범위를 정한다(SD-06).
  • 빠른 선택 버튼과 그 값은 정하지 않았다. 설정값에 예시 숫자를 넣지 않는다(7절).
  • 저장 검색은 상대 범위와 고정 범위를 모두 저장할 수 있다(Q11).

시작 시각은 포함하고 끝 시각은 포함하지 않습니다.
취소적용
  • 범위는 시작 포함·끝 제외다(SD-06). 입력과 표시는 배포 설정의 표시 시간대를 쓴다(SD-07).

상태 4. 실행 뒤 적용 범위 표시

발생 시각 · 최근 NUTC+09:00

적용 범위 2026-11-05 09:15:03 ~ 2026-11-05 10:15:03 (UTC+09:00) · 시작 포함·끝 제외 · 발생 시각 기준 · 최근 N을 10:15:03에 고정

  • 적용 범위는 결과 상태 표시(CM-04)에도 같은 값으로 보인다.
  • 더 보기나 정렬 변경으로 범위가 움직이지 않는다(조사 명세 3절). 실행 뒤 들어온 로그는 다시 실행해야 보인다(SD-28).

상태 5. 수신 시각 기준

수신 시각 · 최근 NUTC+09:00

적용 범위 2026-11-05 09:15:03 ~ 2026-11-05 10:15:03 (UTC+09:00) · 시작 포함·끝 제외 · 수신 시각 기준

목록·발생량·분포·더 보기가 모두 수신 시각을 기준으로 합니다.

  • 수신 시각으로 고르면 목록·발생량·분포·페이지가 모두 같은 축을 쓴다(SD-08).
  • 저장 검색에는 시간 기준도 함께 저장한다(Q08-04).

상태 6. 알림 조사 모드로 열림

알림 조사 수신 시각 · 고정 범위 UTC+09:00

적용 범위 2026-11-05 10:00:00 ~ 2026-11-05 10:05:00 (UTC+09:00) · 시작 포함·끝 제외 · 수신 시각 기준 · 알림이 평가한 구간

  • 알림 링크로 열면 시간 기준은 수신 시각, 범위는 알림이 평가한 절대 구간으로 고정한다(UI-02, SD-08).
  • 범위나 조건을 고치면 알림 조사 모드를 벗어났다고 표시한다. 화면 전체와 규칙·사건 표시는 검색·조사 묶음(UI-02)에서 그린다.
