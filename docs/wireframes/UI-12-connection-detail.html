  • 흐름은 UI-10에서 설정/복구 확인 필요 확인 → 이 안내 → 서버에서 적용 → 이 화면에서 재개 확인이다(6절 수집 복구 확인 필요).
  • WQ-70 문서로 정리: Q10-05는 Q06 수동 재개를 대상·영향 확인과 비밀번호 재확인을 받는 민감 작업으로 적었지만, 화면 흐름 명세는 웹에서 지시하지 않고 안내만 한다. 웹에 누락 확인 같은 확인 단계를 둘지 두 문서를 맞춰야 한다. 정리: 웹에 실행 동작이 없어 재인증 대상이 생기지 않는다. 웹에서 실행하는 기능이 생기면 Q10-05를 적용한다고 명세 UI-12에 적었다.
