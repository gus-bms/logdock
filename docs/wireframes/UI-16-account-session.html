세션 규칙

활동이 1시간 없거나 로그인한 지 24시간이 지나면 다시 로그인해야 합니다.

비밀번호를 잊었거나 계정이 잠겼을 때

서버 운영자가 서버에서 로컬 절차로 재설정합니다. 이메일로 복구하지 않습니다.

  • 비밀번호는 최소 15자이고 긴 문구를 허용하며, 흔하거나 유출된 값은 거부하고 사유를 보여 준다(Q10-03, 7절).
  • 로그아웃은 현재 세션만 끝내고 UI-01로 간다. 이 브라우저에 남긴 검색 조건 복원 정보도 지운다(SD-35).
  • 세션 규칙은 비활동 1시간, 로그인 후 최대 24시간이다(Q10-06). 이메일 비밀번호 복구는 첫 출시 밖이다(3절).
  • 새 비밀번호 다시 입력 칸은 공용 계정이 오타로 잠기지 않게 둔 칸이다(와이어프레임 표기).

  • 보류한 변경은 감사 기록이 복구돼도 자동으로 적용하지 않고 사용자가 다시 바꾼다(2026-11-05 Q10-14 후속 합의).

상태 6. 전체 세션 종료 확인

모든 세션 종료

현재 세션을 포함해 이 계정으로 로그인한 모든 세션을 끝냅니다. 함께 쓰는 사람도 모두 다시 로그인해야 합니다.

취소모든 세션 종료
  • 전체 세션 종료에는 현재 세션도 들어간다(Q10-06).
  • CM-07 사용 목록에 없어 비밀번호를 다시 묻지 않는다(4절 CM-07). 함께 쓰는 사람에게 영향이 있어 확인만 받는다(와이어프레임 표기).
