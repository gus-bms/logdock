  • 진입은 로그인 뒤 첫 화면(상태 2), 상단 메뉴, 저장 검색(UI-05)의 실행, 사건의 조사 열기와 메일 링크(상태 16·17)다. 저장 검색으로 열면 저장한 조건·시간 기준·시간 방식으로 열고, 상대 범위는 열 때의 시각으로 다시 계산한다(5절 UI-02, Q11, Q08-04).
  • 시간 범위는 CM-02 상태 4, 조건은 CM-03 상태 2, 결과 상태는 CM-04 상태 3, 시각·품질 표시는 CM-06 상태 2의 마크업을 가져왔다. 시간 범위를 펼친 모양은 CM-02 상태 2·3, 값 목록은 CM-03 상태 3이다.
  • 검색은 편집기의 조건으로 새로 찾고, 다시 실행은 적용된 조건을 지금 시점으로 다시 찾는다. 실행 뒤 들어온 로그와 늦게 도착한 로그는 다시 실행해야 보인다(SD-06, SD-28).
  • 목록 위에 CM-04 상태, 조회 가능 시작일, 이 범위의 수집 문제, 판정 불가 제외 건수와 보기를 둔다(5절 UI-02, SD-22, SD-32, SD-33). 이 예의 판정 불가는 레벨을 읽지 못한 로그의 레벨 조건과 해석 실패 로그·숫자가 아닌 값의 필드 조건이다. 그래서 해석 실패 로그는 이 목록에 없다.
  • 수집 문제가 없으면 없음, 확인하지 못하면 0으로 채우지 않고 미확인으로 쓴다(1절, 와이어프레임 표기). 수집 연결 보기는 UI-12로 간다(6절 로그가 안 보일 때).
  • 시간별 발생량과 서비스·서버·레벨별 건수만 보여 주고 임의 필드별 건수는 두지 않는다(Q08-08, 3절). 집계는 표본 없이 정확히 세고 막대의 경계·간격·시간대를 함께 보인다(SD-29, 조사 명세 3절). 막대 간격은 정하지 않아 N으로 썼다.
  • 결과 목록은 기준 시각·서비스·서버·레벨·본문 요약 열로 고정하고 CM-06 표시를 붙인다. 필드 열 추가는 첫 출시 밖이다(SD-34, 3절). 본문은 글자로만 그린다(SD-36). 그림의 본문은 합성 예시다.
  • 정렬은 최신순(기본)과 오래된순이다. 같은 시각이면 유일한 보조 정렬키로 정하고 같은 로그 흐름 안에서는 원본 순서를 지킨다(SD-26). 다음 행은 더 보기로 불러오며 한 번에 불러오는 행 수는 정하지 않았다(SD-27, 7절). 목록 행 수를 전체 건수로 쓰지 않는다(SD-29).
  • 행을 누르면 이벤트 상세(UI-03) 패널이 이 화면 위에 열린다. 검색 조건은 URL에 넣지 않고, 새로고침 복원은 세션 범위로 하며 로그아웃 때 지운다(1절, SD-35).
  • 조건 저장(상태 12~14)과 현재 조건으로 알림 규칙 만들기(상태 15)는 화면 제목 줄 오른쪽에 둔다(와이어프레임 표기).
  • WQ-06 설계로 넘김: 판정 불가 보기가 결과에서 뺀 로그를 어떻게 보여 주는지(이 목록을 바꿔 보여 줄지, 따로 열지) 문서에 없다. 기본안: 같은 화면의 목록을 판정 불가 로그만으로 바꾸고 원래 결과로 돌아가는 버튼을 둔다.

상태 15. 현재 조건으로 알림 규칙 만들기

복사할 조건
(서비스 주문 또는 결제) 그리고 (환경 운영) 그리고 (레벨 ERROR 또는 WARN) 그리고 (본문에 "timeout" 포함) 그리고 (http.status 500 이상)

복사한 뒤에는 서로 따로 바뀝니다. 이 검색 조건이나 저장 검색을 고쳐도 알림 규칙은 바뀌지 않고, 알림 규칙을 고쳐도 저장 검색은 바뀌지 않습니다.

알림은 중앙 수신 시각으로 셉니다. 시간 구간과 임계 건수는 기본값이 없어 규칙 편집에서 정합니다.

취소규칙 편집 열기
  • 현재 조건으로 알림 규칙 만들기는 조건을 복사해 알림 규칙 편집(UI-07)을 연다(5절 UI-02, TD-05). 저장 검색·규칙과는 복사 관계라 한쪽을 고쳐도 다른 쪽은 바뀌지 않는다고 알린다(SD-30).
  • 알림 집계는 중앙 수신 시각 기준이고 시간 구간과 임계 건수는 기본값이 없다(Q12-01, UI-07 요소). 필터가 하나도 없는 조건이면 UI-07이 경고한다(UI-07 그릴 상태).
  • 안내를 확인 창으로 보여 준 것은 와이어프레임 표기다.
  • WQ-10 설계로 넘김: 복사 관계 안내를 이 확인 창에 둘지 UI-07 첫 화면에 둘지 문서에 없다. 묶음 3의 UI-07과 맞춰 한 곳에만 두어야 한다. 기본안: UI-07 위쪽에만 둔다. UI-07은 확인 창 없이도 열리므로 그곳에 있어야 한다. UI-02 상태 15의 확인 창은 화면 설계에서 뺀다(WQ-39와 같음).
  • WQ-11 문서로 정리: 검색의 시간 범위와 시간 기준은 규칙으로 넘기지 않는다고 그렸다(규칙의 시간 구간은 기본값 없음, 집계는 수신 시각). 맞는지 확인이 필요하다. 정리: 그림이 맞다. 규칙의 시간 구간·임계는 기본값 없이 직접 입력하고(Q12-01) 집계는 중앙 수신 시각이다.
