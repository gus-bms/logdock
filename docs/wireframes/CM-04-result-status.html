CM-04 결과 상태 표시

검색 결과 위에 두는 상태 표시다. 상태 이름은 실행 전, 조회 중, 완료, 완료 0건, 부분·한도, 시간 초과·오류, 취소, 만료·접근 제한을 그대로 쓴다. 아래 그림의 발생량·분포·목록 자리는 상태를 보이기 위한 축약이며, 실제 배치는 UI-02에서 그린다.

상태 1. 실행 전

실행 전 조건과 시간 범위를 정한 뒤 검색을 누르세요. 검색
아직 검색하지 않았습니다. 발생량·분포·목록 자리에 0을 표시하지 않습니다.
  • 실행 전에는 결과 자리에 0건이나 빈 표를 보이지 않는다. 검색하지 않은 것과 0건을 구분한다(조사 명세 3절).

상태 5. 완료 0건: 범위 일부가 만료됐을 수 있음

완료 0건 적용 범위 2026-04-20 00:00:00 ~ 2026-05-10 00:00:00 (UTC+09:00) · 발생 시각 기준 10:15:03까지 수신된 로그 기준

일부 만료됐을 수 있음: 조회 가능 시작일은 2026-05-05(수신 시각 기준)입니다. 보관 기간과 조기 삭제는 수신 시각으로 계산하므로, 이 범위의 로그 일부는 이미 삭제됐을 수 있습니다.

  • 발생 시각 범위만으로 만료를 단정하지 않고 일부 만료됐을 수 있음으로 표시한다(SD-33). 결과가 있는 완료에서도 같은 문구를 쓴다.

  • 그림의 사유 코드와 요청 참조는 자리 표시다. 실제 이름은 API 설계에서 정한다(9절).

만료·접근 제한 검색 결과를 이어서 불러올 수 없습니다. 같은 조건으로 다시 검색하세요. 다시 검색
만료·접근 제한 로그인 세션이 만료됐습니다. 다시 로그인하면 이 화면으로 돌아옵니다. 다시 로그인
  • 현재 조회 가능한 범위와 일반 안내만 보여 주고, 권한 밖 데이터가 있다는 사실을 알리지 않는다(조사 명세 3절).
  • 더 보기 위치가 만료되면 다시 검사하고 재검색을 안내한다(SD-27). 세션은 비활동 1시간 또는 로그인 후 최대 24시간에 끝난다(Q10-06).
