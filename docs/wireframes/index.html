LogDock 와이어프레임

첫 출시 화면의 회색조 저충실도 와이어프레임이다. 기준은 화면 흐름 명세이며 화면 구현 승인이나 구현 코드가 아니다.

그리는 규칙·순서·검토 기준: 화면 흐름 명세 8절 · 정하지 않은 수치: 7절의 N

파일 작성 방식

  • 모든 파일은 wireframe.css 하나만 불러온다. 외부 스크립트·글꼴을 쓰지 않고 브라우저에서 바로 연다.
  • 파일 제목과 <h1>은 UI-02 로그 탐색처럼 ID와 이름으로 쓴다.
  • 한 파일 안에 상태를 상태 1.부터 차례로 그리고, 상태마다 근거 ID를 주석(ul.wf-notes)에 적는다.
  • 화면 전체는 div.wf-screen 안에 CM-01 상단 메뉴부터 그리고, 현재 메뉴에 is-current를 붙인다.
  • 예시 시각은 2026-11-05, 표시 시간대는 UTC+09:00으로 쓴다. 시간대는 배포 설정 하나를 쓰는 합성 예시다.
  • 문서에 없어 정해야 할 점은 주석에 검토 항목:으로 적는다. 2026-11-05까지 나온 91건은 처리를 정해 WQ-nn 설계로 넘김:처럼 바꿨고 결과는 정리표(docs/planning/wireframe-review-items-v0.1.md)에 있다.
